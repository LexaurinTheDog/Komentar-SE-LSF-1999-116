# Kommentar till lagen (1999:116) om skiljeförfarande

Kommentar till svensk författning: **Lag (1999:116) om skiljeförfarande** (SFS 1999:116). Kommentaren omfattar **66 enheter** (64 paragrafer, 1–60 §§ inklusive 4 a, 23 a, 27 a och 45 a §§, samt två uppsättningar övergångsbestämmelser) fördelade på 4 kommentarskapitel; vid varje paragraf återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 2018:1954** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2025-10-17).

Källa: [rkrattsbaser.gov.se/sfst?bet=1999:116](https://rkrattsbaser.gov.se/sfst?bet=1999%3A116) · [data.riksdagen.se/dokument/sfs-1999-116](https://data.riksdagen.se/dokument/sfs-1999-116.json)
